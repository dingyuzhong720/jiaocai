𝓞𝓞-Notation
• 𝓞𝓞-Notation gibt Wachstumsordnung nur näherungsweise an
• Nach Definition gilt z.B. auch
1020 𝑛𝑛2 ∈𝒪𝒪1/100 ⋅𝑛𝑛3
• Jedoch gilt 1020 𝑛𝑛2 ≤1/100 𝑛𝑛3 erst ab 𝑛𝑛0 = 1022
• Eingabegröße von 1022 unrealistisch, daher wäre die obige

• In der Praxis kommen jedoch eher kleine konstante Faktoren vor,

– Die ungefähre Abschätzung der Laufzeit eines Algorithmus
– Den näherungsweisen Vergleich der Laufzeit verschiedener 
Algorithmen
• Vor allem: sinnvoll vor der detaillierten Implementierung

#define NOT_FOUND -1
int binsearch(int A[], int key, int l, int r)
{ 
int k;
while (r >= l) { 
k = (l+r)/2;
if (key == A[k]) return k;
if (key < A[k]) r = k-1;
else l = k+1;
}
return NOT_FOUND;
}
