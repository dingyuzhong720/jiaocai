Beim Post-Inkrement (analog: Post-Dekrement) wird der Ausdruck zunächst 
ausgewertet und dann inkrementiert. D.h. im Beispiel wird der „alte“ Wert von p

The class name itself acts as constructor, which is called when an object of that 
class is created. When the object is deleted, the deconstructor method is called,

Auswahl der Methode während der Ausführung.

Zugehörigkeit zu einer (Sub)Klasse

At this point, we know the essential elements to introduce dynamic 
polymorphism - a concept where the binding of a function call with an 
appropriate declaration happens during run-time.
To enable this, we introduce the keyword virtual in the base class to label 
methods that should be considered for this. This triggers the compiler to create a 
table of potential methods to be used.
A typical application of this is handling objects of the base or derived class with 
the same code as shown in the given example:
We declare a pointer to an object of the base class. Depending on the user input, 
either an object of the base class or any of the two derived classes is created.
The call of show is then dynamically bound to the (sub-)class the base class of the 
object the pointer is pointing to, i.e., the class of the handled object determines 
during run-time the binding of show.

case 'E': source = &en; break;
case 'F': source = &fr; break;
}

case 'E': target = &en; break;
case 'F': target = &fr; break;
}

auto it = find(source->begin(), source->end(), word);
size_t i = distance(source->begin(), it);
if( i<source->size() && i<target->size() ) res = (*target)[i];
return res;
}                
};
